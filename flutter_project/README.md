# VocoPlan (Flutter Edition)

Vollständig lokale Sprach-Terminplanungs-App für Android und iOS.

## Features
- **Design & Layout**: Edles Blau-Schema (Modern Blue / Indigo Akzente) mit blendfreiem Dark Mode und augenschonendem Hellmodus.
- **Zentrales Sichtfenster**: Mindestens 10–12 Zeilen großes Textfeld, in dem alle extrahierten Daten (Anlass, Zeitpunkt, Ort, Notizen, Erinnerungszeit) übersichtlich formatiert werden.
- **Echte Push-to-Talk-Sprachaufzeichnung**: Hold-to-Record mit Daumen-Bedienung und hartem 600-Zeichen-Limit.
- **On-Device Parsing**: 100% lokale deutsche Spracherkennung und Analyse ohne Cloud und ohne externe API-Keys.
- **Zwei Speicher-Buttons**: Direktes Speichern im Standard-Gerätekalender oder gezielt im verknüpften Google-Kalender.
- **Erinnerungen**: Schnellauswahl (1 Std. bis 1 Woche) und aufklappbarer Regler für individuelle Tage und Stunden.

## Starten
```bash
flutter pub get
flutter run
```
